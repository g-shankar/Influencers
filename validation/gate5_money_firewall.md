# Gate 6 — money firewall

Every dollar figure that appears in any pilot report, message, or pitch
material must carry exactly one tag:

- `[FACT — <source>]` — a number someone actually published: an affiliate
  program's stated commission rate, a vendor's list price, a bank's published
  interchange schedule. The source must be named and dated.
- `[MODEL — <assumption>]` — a number we calculated: markups, take rates,
  illustrative per-trip economics. The assumption behind it must be stated
  in the same paragraph.

## Banned
- Presenting a MODEL number as a guaranteed, typical, or expected outcome.
- "Up to" figures without the conditions attached.
- Blending FACT and MODEL numbers into one total without labeling each part.
- Any new money figure introduced without a tag. No tag = the report doesn't ship.

## Checklist (before any report/message with economics goes out)
1. Every $ figure tagged FACT or MODEL.
2. Every FACT has a named, dated source.
3. Every MODEL states its assumptions and what would break them.
4. Totals built from mixed inputs show the FACT/MODEL split.
5. Nothing in the text contradicts the tags (no "will earn" next to a MODEL tag —
   it "would earn IF <assumptions>").
