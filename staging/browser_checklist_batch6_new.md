staging/selection_batch6_new.csv using the exact 23-column order from batch 5:
batch,handle,platform,name,niche,followers_approx,followers_observed,followers_source,
profile_url,discovery_source,identity_check,identity_method,content_fit,
content_fit_evidence,reach_floor,engagement_observed,activity_check,purchase_intent,
exclusions_check,decision,notes,check_date,selector

Constants: batch=6, platform=tiktok, decision=include, check_date=2026-09-16,
selector=batch6-worker. followers_observed = exact live count; followers_source =
"tiktok_profile_2026-09-16". activity_check evidence = video URL + create_time →
date. content_fit_evidence = itinerary URL + create_time → date.
engagement_observed = observed counts or unknown (never estimated).
purchase_intent = present|absent|unknown per creator.

Then add one extraction per passing creator to staging/itineraries_batch6_new.json
(batch, extractions[]; each itinerary: title, destination, days, summary,
source_urls[], confidence, items[] with day,item_type,name,location,details,
booking_link,price_hint — null where the source doesn't state it).

Do NOT write CSV/JSON rows for creators that fail any gate. If fewer than 11 pass,
report the shortfall rather than filling with unverified rows.
